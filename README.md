# Blaze5RP Launcher

Desktop launcher for the Blaze5RP project, built with Electron, React, TypeScript and Vite.

## Requirements
- Node.js 20 or newer
- Windows 10/11 for the Windows launcher build

## Development
```bash
npm install
npm run dev
```

## Build
```bash
npm run dist
```

The first version includes the launcher interface, local settings storage, folder selection and a basic RAGE MP executable launch attempt. Server status, website authentication, DPO balance synchronization and the real registration URL will be connected when the server/site API details are ready.

Do not commit passwords, API keys, tokens or private environment files.
